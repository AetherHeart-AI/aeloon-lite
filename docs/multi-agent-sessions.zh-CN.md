# 本地多 Agent 会话

本地会话由消息流、成员、当前工作区和这条会话产生的文件组成。你和若干 Agent 实例待在同一条对话里。实例入场时拷贝定义并冻结。

## 成员

一次只有一个人说话。会话有一位**主持人**：成员列表里的第一个 Agent。一条消息只到一个 Agent —— mention 块点到的第一个，没点到就是主持人。点到多个也只到第一个，其余的作为普通内容留在消息里，拿着发言权的 Agent 看得见。Agent 的回复不会唤醒任何 Agent。从未说过话的实例可以移除，任何成员都可以被设为主持人。

输入框里的 `@` 仍可搜索文件。从菜单里选中一个 Agent 会写入 mention 块；纯文本 `@名` 不会路由。

## 转交发言权

拿着发言权的 Agent 可以调用 `transfer`，把对话交给另一个成员。那个成员看着同一条消息流、在同一个工作区里作答，也可以再交下去。一轮结束时没有转交，发言权就回到你手上，不再有人说话。

一条消息最多换手四次。到上限时 `transfer` 直接不出现，当前 Agent 只能作答，链条自然终止。取消当前持有发言权的 Agent 也会终止整条链。失败的实例不推进自己的读到位置。

## 兼容性

升级前建立的旧会话仍按默认助手打开，不会获得成员列表，也没有可以转交的对象。

本版 Desktop 仍可连接旧版 Runtime 进行普通对话。mention 路由、会话成员和工作区文件提及需要支持 `thread.member` 的 Runtime；早于本版的 Runtime 不接受 `set_host`，也无法转交发言权。`fs.search` 不可用时，对话仍可用，只是不提供文件建议。
