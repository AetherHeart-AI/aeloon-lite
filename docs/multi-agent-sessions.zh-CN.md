# 本地多 Agent 会话

本地会话由消息流、成员、当前工作区和这条会话产生的文件组成。你和若干 Agent 实例待在同一条对话里。实例入场时拷贝定义并冻结。

## 成员

第一个入场的 Agent 默认活跃，之后入场的默认静默。活跃实例会回答没有 mention 的用户消息；静默实例只在 mention 块点到它时回答。Agent 的回复不会唤醒任何 Agent。从未说过话的实例可以移除。

输入框里的 `@` 仍可搜索文件。从菜单里选中一个 Agent 会写入 mention 块；纯文本 `@名` 不会路由。被点到的实例按入场顺序串行执行，共用当前工作区。后跑的看得见先跑的。失败的实例不推进自己的读到位置。

升级前建立的旧会话仍按默认助手打开，不会获得成员列表。

## 委派

Agent 仍可通过 `task` 工具把一段有范围的子任务交给另一个定义。结果只回到调用者，不进入会话。委派是工具，不是第二种 Agent。

## 兼容性

本版 Desktop 仍可连接旧版 Runtime 进行普通对话。mention 路由、会话成员和工作区文件提及需要支持 `thread.member` 的 Runtime。`fs.search` 不可用时，对话仍可用，只是不提供文件建议。
