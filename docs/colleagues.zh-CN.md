# 同事与对话

[English](colleagues.md) | 简体中文

Aeloon 里的每个 Agent 都是一位同事：有名字、有分工、有一张自己的桌面。你和同事之间是一条持续的对话，不需要选择工作区，也不需要管理会话。

## 同事列表

- 左侧是同事列表。首次安装自带四位：助手、研究员、需求分析师、方案架构师。
- 在「Agents」页可以新增同事、修改人设（名字、简介、指示、模型、可用工具），也可以删除。
- 修改立刻生效：同事的下一次回答就按新的人设来。删除同事后，和他的对话仍可查看，但不能再发消息。

## 对话与新话题

- 点进一位同事，看到的是当前对话，直接输入即可。
- 一个话题聊得太长时，点「新话题」。旧话题归档到这位同事的「历史」里，随时可以翻看；新话题从空白开始，但同事的桌面文件和记忆都还在。
- 同事正忙时你仍然可以发消息，它会作为插话并入当前工作。

## 文件

- 把文件拖进对话，就是给这位同事的附件，会出现卡片，内容可以进入对话。
- 把整个文件夹拖进对话，文件会原样放到这位同事桌面的 `inbox/` 目录里，不建卡片、不占对话篇幅，消息里会自动写明放了哪些文件。适合一次交一批文档。
- 同事交付的文件显示为产物卡片，可以打开或保存。把产物卡片拖进另一位同事的对话，就是把文件转交给他。
- 右侧「文件」面板列出这位同事收到的附件和交付的产物。

## 请教别的同事

- 给一位同事装上**请教同事**技能，它遇到需要别人专长才能判断的问题时，会私下去问另一位同事。没装这个技能就不会。
- 回答你的始终是你正在对话的这位同事：它读完对方的答复，用自己的话写给你。被请教的那位不会直接跟你说话。
- 回答下面会出现一栏**私聊**，一次请教一张卡片：问的是谁、结果如何、答复的第一行。点开可以看到当时问出去的原话和对方的答复。卡片是给你看的，你不能插进那段对话。
- 请教不是一次会话。它不会出现在你的会话列表里；在群里也不会把内容发到群中。
- 边界：一次回答最多请教三次，被请教的同事不能再去请教别人，你点停止时请教一并停止。主持群聊的那位同事不会请教，它在群里是把活派出去。
- 被请教的同事做出来的文件不单独交付。他们共用一张桌子，交不交给你由回答你的那位决定。

## 远程 Runtime

连接远程服务器时，同事和他们的桌面都在服务器上，本机只是客户端。安装与配对见[远程部署教程](remote-deployment.zh-CN.md)。
