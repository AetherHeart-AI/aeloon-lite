# 工作台产品形态

2026-09-11 更新。浏览器与账号体系的实施目标见 [design-org.md](design-org.md)，由公开 #119 跟踪。
实施以最新 origin/main 为基线，并协调发布 Desktop 稳定版；文档中的目标不代表已经发布。

## 一句话

一个组织共用一台 Runtime，界面是单聊和群聊。Agent 是同事——出现在联系人里、能被拉进群、
一次做一件事、有自己的桌面和记忆。人和人也能聊。没有工作区、没有项目、没有终端。

## 导航

- **左侧图标栏**：联系人、附加功能、基础设置。命令搜索保留快捷键。
- **联系人目录**：顶部是这台 Runtime 的名字、搜索和建群。四个分类——**全部**、**Agent**、
  **同事**、**群聊**。
  - Agent 里 **我的助理** 唯一；从模板库加进来的是我私有的副本；定义已删但还留着对话的，
    仍然进得去它的历史。
  - 同事就是这台主机上的其他人。单机没有别人时这里是一句说明，不是占位联系人。
- **主区**：当前对话。
- **右侧折叠面板**：从右上角切换，同一时刻只开一个——**历史会话**、**文件**、**群管理**、
  **Agent 设置**。默认收起。
- 换联系人就收起面板，面板里没保存的东西丢掉，聊天输入框不受影响。
- 打开应用回到**上次选择的那个对象和那条对话**。换一台服务器就是另一份选择，不共用。

## 单聊

- 点开一位同事就是打开我和它的当前对话；它还没有对话就建一条。
- **新会话**在右上角：开一条新的，上下文不带过去。桌面文件、记忆、模型和技能都留着。
- **历史**是右上角的折叠面板，列这位同事的对话。选中就接着聊，不是只读；发新消息也不会
  把别的对话的上下文带进来。
- 删掉一条对话之后可以**撤销最近一次删除**，回来的是原来那条和它的消息，不是一份复制。
  删对话不清空这位同事的文件、记忆和配置；它正在干活的那条不让删。
- 删掉当前那条就切到剩下里最近用过的一条；全删光了就是空态，再发消息自动建一条。
- 点开一个人就是人和人的私聊，里面没有 agent，也不产生任何模型调用。

## 群聊

- 成员可以是人也可以是 agent，用同一套拉人的逻辑和界面。
- 群助理作为默认响应者；显式结构化 @ 路由到指定 Agent，文本 @ 不路由。
- 沿用现有转交和步数上限，不使用活跃/静默旧设计或多人并行抢答。
- 每个 agent 在群里是一份**独立实例**：自己的 session、自己的桌面、自己的读指针。它和这个
  agent 在我私聊里的那份不是同一个。
- 醒来时它看到的是「上次我说话之后这里发生了什么」，作为环境变化补进上下文；太长先摘要。
- **群桌面是共享的**：谁传进群的文件，群内所有 agent 都读得到。想让它用私人文件，得显式
  传进群。
- **群管理**面板：群名、群公告、成员增删。群助理不可移除。

## Agent

- **详情面板**（右上）：状态、工作职责（它是怎么定义的）、技能列表、成长档案。
- **技能**在这里增删，装是在 Skill 市场装。能力差异靠技能表达，工具不按 agent 限制。
- **成长档案**两层：共有层是它自己的手艺，跨用户累积，只写方法论不写事实；对人层是它对我
  的了解，只有我这边看得到。群实例只用共有层。
- **头像上的角标是待处理队列的深度。** 每个实例一次处理一条消息，私聊与不同群的实例各自排队。
- **模型跟着实例走**：我的私聊一份，它在的每个群各一份，互不覆盖。拉它进群时，拿我私聊里
  当时的有效模型当这个群的初始值。在群里改模型只改这个群的这一份，不动公共定义。没有显式
  选过就是「使用默认模型」，跟着 Agent 定义走；接着聊一条旧对话，用的是这条对话当时选定的
  模型。

## 文件与交接

- **文件**面板列的是**这个对象名下的全部文件**——我和这位同事的，或者这个群的。跨它的所有
  对话保留，删对话不删文件。可以按目录看、按名字搜、建文件夹、改名、下载。
- 每个文件记得**是哪条对话产生的**：那条还在就跳得回去，删了就跳不了，但文件照样读得到、
  下得了；撤销删除之后跳转也回来。改名不影响消息里的引用。
- **交接就是转发**：选中若干消息和文件，发成一张卡片给另一个会话。对方能预览，agent 读得懂。
  卡片是复制，不是引用——之后改原件不影响它。

## 附加功能

- **Skill 市场**：导入或下载 skill，装到当前用户的 Skill 目录，保持个人归属。装 skill 和给某个
  agent 绑 skill 是两件事。
- **Agent 模板库**：把一个模板加进联系人，从此是我私有的一份，模板之后怎么改都不影响我这份。
- 这里只有这台 Runtime 上真装着的东西和内置模板。没有在线商店，没有作者、评分和安装量。

## 组织

- **联系人就是这台主机上的用户列表**，界面里没有邀请流程。
- 管理员在 `/admin` 管理账号；首位管理员由 CLI 交互创建。用户使用用户名和密码登录，
  可以自行重新登录和修改密码。账号有 admin/user 角色，不开放注册。
- **换一台服务器就是换一个账号**，两个完全独立的空间，不做同步。
- **单机模式**：没有组织、联系人为空，但仍然可以建群——我和我的几个 agent。

## 设置

- 首屏只有外观和阅读：**颜色模式**（浅色 / 深色 / 跟随系统）、**风格**、**字号**、
  **消息时间**。语言、字体、默认展开执行过程收在「更多显示」里。
- **风格**五套：Alloy（默认）、Classic、Apricot、Mist、Iris，每套都有浅色和深色。
- 远程 Provider、云账号、搜索密钥、默认模型和全局工具统一由管理员配置，普通用户选择开放模型。
- `/admin` 管理用户资料、角色、重置密码和启停；停用保留数据，保护最后一位管理员。
- Desktop 远程连接使用地址、用户名、密码，保留本地与多连接。密码不保存，会话仅主进程保存。
- 浏览器入口为 `/login`、`/` 和 `/admin`，聊天、Agent、历史及文件复用现有工作台。
- 文件以认证 HTTP 流式下载；主动内容强制下载，文件管理器入口仅 Desktop 显示。
- 没有工作区、没有项目、没有 Memory 面板。

## 明确不做的

- 一个 session 里多个 agent 协同或抢答。
- 无限制的 Agent 互相唤醒。
- 工作区、项目、Git、终端、文件浏览器。
- 开放注册、网页修改 HTTPS/端口/监听/服务启停参数。
- 配对码、设备令牌、二维码、TOFU、Desktop SSH 自动部署及系统凭据库。
- 冻结的交接资产、授权与撤销。
- 按人计量用量。

## 还没定的

- **定时任务**：设计稿上有这个入口，这一轮没讨论过，形态未定。
- **信任边界已定**：仅受信任团队，共享系统账号执行，不承诺恶意用户间 Shell 隔离。
  现有沙箱默认开启，远程仅管理员可关闭，关闭时说明共享系统账号权限。

## 安装与发布

一份 dist/client 同供 Desktop 和服务器，沿用统一版本、摘要和 Release；服务器无需 Node/Bun/Vite。
远程必须使用全新 --data-dir，旧部署和数据保留，不迫使 Desktop 本地数据重置。
证书必须覆盖访问地址并被客户端信任，CLI 和服务管理器维护部署；配套稳定版不自动切换生产服务。
