# future 的最终形态

`future` 四段做完之后产品长什么样。依据是 [design-org.md](design-org.md) 里的决定；
这里只写「是什么」，不写「为什么」。

## 一句话

一个组织共用一台 Runtime，界面是单聊和群聊。Agent 是同事——出现在联系人里、能被拉进群、
一次做一件事、有自己的桌面和记忆。人和人也能聊。没有工作区、没有项目、没有终端。

## 导航

- **左侧图标栏**：会话、联系人、Skill 市场、设置。
- **会话列表**：顶部两个标签，**单聊** 和 **群聊**。
  - 单聊分四组：**我的助理**（默认助理，唯一）、**我的 Agent**（从模板库加进来的私有副本）、
    **团队成员**（这台主机上的人）、**已离开**（定义已删但还留着对话的）。
  - 群聊列出我在的群。
- **主区**：当前会话。
- **右侧折叠面板**：从右上角切换，三选一——**历史会话**、**会话资产**、**Agent 详情**。
  默认收起。

## 单聊

- 点开一位同事就是打开我和它的当前对话；它还没有对话就建一条。
- **新会话**在右上角：归档当前那条，开一条新的。桌面文件和记忆留着，上下文不带过去。
- **历史**是右上角的折叠面板，列这位同事的已归档对话，只读打开。
- 打开应用回到**上次选择的那条对话**，不是最近更新的那条。
- 点开一个人就是人和人的私聊，里面没有 agent。

## 群聊

- 成员可以是人也可以是 agent，用同一套拉人的逻辑和界面。
- 每个群有**唯一一个群助理**，就是默认助理在这个群里的一份实例，**不可更换**。它身上有
  活跃/静默的开关——默认活跃，人多嫌吵就调静默。
- 群里其他 agent 一律静默，**被真 @ 才醒**。文本里打的 @ 只是文字。
- **只有群助理能真 @ 别人。** 人可以 @ 任何 agent；agent @ 人只产生通知，不唤醒。
- 每个 agent 在群里是一份**独立实例**：自己的 session、自己的桌面、自己的读指针。它和这个
  agent 在我私聊里的那份不是同一个。
- 醒来时它看到的是「上次我说话之后这里发生了什么」，作为环境变化补进上下文；太长先摘要。
- **群桌面是共享的**：谁传进群的文件，群内所有 agent 都读得到。想让它用私人文件，得显式
  传进群。

## Agent

- **详情面板**（右上）：状态、工作职责（它是怎么定义的）、技能列表、成长档案。
- **技能**在这里增删，装是在 Skill 市场装。能力差异靠技能表达，工具不按 agent 限制。
- **成长档案**两层：共有层是它自己的手艺，跨用户累积，只写方法论不写事实；对人层是它对我
  的了解，只有我这边看得到。群实例只用共有层。
- **头像上的角标是待处理队列的深度。** 一个 agent 一次只做一件事——它在群里干活时，
  我在私聊里发的消息在排队。

## 资产与交接

- **会话资产**面板分两组：**我传的**和**它产的**。只列这次会话的，不列目录。
- **交接就是转发**：选中若干消息和文件，发成一张卡片给另一个会话。对方能预览，agent 读得懂。
  卡片是复制，不是引用——之后改原件不影响它。

## 市场与模板

- **Skill 市场**：导入或下载 skill，装到这台 Runtime 上，全组织可见。
- **Agent 模板库**：把一个模板加进联系人，从此是我私有的一份，模板之后怎么改都不影响我这份。

## 组织

- **联系人就是这台主机上的用户列表**，界面里没有邀请流程。
- 管理员在服务器上 `user add alice` 发一个一次性邀请码，她在桌面粘一次，这台设备从此就是她。
  没有密码。
- **换一台服务器就是换一个账号**，两个完全独立的空间，不做同步。
- **单机模式**：没有组织、联系人为空，但仍然可以建群——我和我的几个 agent。

## 设置

- Provider 全局一份，全组织共用，人人可改。
- 用户管理：发码、列人、移除。
- 通用（语言、主题、字号）、技能、诊断。
- 没有工作区、没有项目、没有 Memory 面板。

## 明确不做的

- 一个 session 里多个 agent 协同或抢答。
- agent 之间互相唤醒（群助理是唯一例外）。
- 工作区、项目、Git、终端、文件浏览器。
- 密码登录、界面里的邀请流程、权限分级。
- 冻结的交接资产、授权与撤销。
- 按人计量用量。

## 还没定的

- **定时任务**：设计稿上有这个入口，这一轮没讨论过，形态未定。
- **沙箱隔离**：形态已经想清楚（见 design-org.md 第 8 节），但不排在四段里，作为对外部署
  前的准入条件单独挂着。
