# 组织、账号与浏览器工作台设计

状态：2026-09-11 确认的实施目标，公开工作项 [#119](https://github.com/AetherHeart-AI/aeloon-lite/issues/119)。
本记录替代 2026-09-07/08 的无密码设备配对、人人管理员、future 分支和源码测试决策。
功能完成与发布以关联工作项、合并记录及验证结果为准，本文不表示已经交付。

## 部署与信任边界

受信任团队共用一台主机、一个 Runtime 和共享系统账号。应用 HTTP、RPC、插件入口及实时和
重放事件按稳定 user_id、角色与群成员关系授权；管理员没有查看其他用户私有内容的特权入口。
不承诺恶意用户之间的 Shell 隔离。现有沙箱默认开启，远程仅管理员可改
`tools.sandbox_enabled`；关闭时明确说明 Shell 使用共享系统账号权限。开启也不扩大信任承诺。

Runtime 同进程引入 aiohttp，提供静态资源、认证 HTTP、流式文件下载与 `/rpc` WebSocket。
保留二进制帧、请求分发、事件游标和重放；适配器明确限定发送等待、队列、慢客户端、心跳、
断连清理，并关闭压缩。没有 SSR 和额外业务进程。
HTTPS、监听地址、端口、证书及启停由 CLI、部署工具和服务管理器维护，网页不维护部署参数状态机。

## 账号与会话

账号包含稳定 user_id、用户名、独立盐 scrypt 密码哈希、admin/user 角色和启停状态。
不开放注册。首位管理员由 CLI 交互创建；无可用管理员拒绝启动远程服务。CLI 提供密码恢复。
管理员可以在 `/admin` 创建账号、修改资料和角色、重置密码及启停账号；停用保留数据，禁止
停用或降级最后一位管理员。用户可以自行重新登录和修改自己的密码，无需管理员重新发码。
密码不进入命令参数、日志或持久客户端配置；登录限流、密码验证并发有上限，失败统一提示。

会话使用不透明随机令牌，服务端仅存摘要；30 天未使用过期。活跃客户端调用认证会话接口滑动
续期，浏览器同步更新 Cookie；网络心跳不续期，不设七天强制重新登录。
退出撤销当前会话；改密、重置密码、停用、角色变化撤销用户全部会话并关闭连接。
连接绑定身份，不能原地切换用户；切换后迟到请求/响应和缓存不得混入新账号。

浏览器使用 Secure、HttpOnly、SameSite=Strict Cookie。Cookie 写接口（含登录、退出、续期）
严格校验 Origin，只接受 JSON，不开放跨源凭据访问；GET 无业务写操作。不引入独立 CSRF 令牌。
WebSocket 同样校验 Origin，缺失或不匹配时拒绝 Cookie 认证。
Desktop 主进程通过相同登录服务取得会话，使用 Authorization；只保存地址、用户名和可撤销
会话，密码不落盘、会话不进入渲染层。会话文件原子写入，并以平台文件权限保护。

## 配置与个人资产

最新 main 曾采用每人独立 Provider/云账号配置；本轮远程模式改为管理员统一维护 Provider、
云账号凭据、搜索密钥、默认模型及全局工具配置。普通用户选择开放模型，不能修改管理员配置。
个人资料、Skill、Agent 与会话偏好保持原归属；群聊依成员关系可见。Desktop 本地配置继续独立。
云账号沿用文件凭据存储并补齐原子写入；删除 Keychain、safeStorage 等系统凭据库调用。
旧凭据不读取、不迁移、不删除，需要时重新登录。

Agent 模板加入即复制为个人定义。私聊与群内实例各自持有模型配置、桌面和会话；文件跨该对象
的历史会话保留。群聊使用现有主持/转交规则：默认由群助理响应，显式提及路由到指定 Agent，
不恢复旧版多人同时抢答或无限互相唤醒设计。成长记忆继续走现有 skill 与 CLI，群实例不读取
任何个人对人记忆。模型指令不作为恶意租户的隔离承诺。

## 浏览器、Desktop 与文件

复用现有 React 工作台和桥接接口，仅为公共 RPC、事件及连接状态增加浏览器适配，不建立新的
通用客户端框架。页面为 `/`、`/login`、`/admin`；尾斜杠重定向到规范路径。Vite 保持相对资源
路径，直接访问和刷新均可加载；未知 API、缺失静态资源不得回退 HTML。
刷新与断线恢复快照和事件，不自动重发结果不明的写请求；关闭浏览器不停止服务器 Agent。
Desktop 保留本地、多连接、启动、卸载、本地路径等明确的专属能力。

上传沿用附件协议和大小限制；附件与产物各提供认证 HTTP GET 下载，复用归属、路径及软链
检查，流式发送并清理断连资源，不把整个文件 base64 化。文件名与类型合理，图片、文本、PDF
保持预览；HTML、SVG 等主动内容强制下载，不能在登录站点同源执行。文件管理器入口仅 Desktop 显示。
删除配对码、二维码、设备令牌、指纹信任、Desktop SSH 自动部署及对应 CLI/IPC/依赖/测试。

## 构建、部署与发布

只构建一份 `dist/client`，用于 Desktop 打包和服务器托管。静态资源归档进入统一 Release，
沿用版本与发布摘要校验；安装器将兼容 Runtime/UI 作为一组安装，生产无需 Node、Bun 或 Vite。
沿用安装脚本、命令与产品名称，不建立独立 Web 版本体系。

远程通过 `--data-dir` 指定全新目录，遇到旧目录明确拒绝，不迁移、不 reset。
不提升全局数据版本迫使 Desktop 本地重置。测试使用独立目录和端口，旧服务与数据保留。
IP/域名均可使用，但证书须覆盖访问地址并受客户端信任；前提是公网可信证书或预装内网 CA。
不保留 TOFU，不承诺自签证书开箱即用；证书签发、续期、替换和重启由部署工具维护。

实施从各仓库最新 `origin/main` 开始，保留未提交改动；不再使用 future 分支。
先 Runtime 协议与认证，再 UI/管理页面/Desktop，再安装与协调发布。更新协议版本和生成类型，
握手返回账号身份及能力并移除设备字段，不兼容客户端明确报错。
CI 全绿后按依赖顺序合并，发布配套 Runtime、静态资源和 Desktop 稳定安装包；不要求源码构建，
不自动升级或切换现有生产部署。发版后同步三个本地仓库。

## 验收边界

两名普通用户和一名管理员覆盖私有归属、群共享、管理越权、配置生效、会话撤销、密码重置、
账号切换迟到响应、下载路径/软链。复用 Unix/WebSocket 转录等价回放，补充慢客户端、队列、
重连/重放、下载中断与超过单帧大小的产物下载。
系统 Chrome 覆盖登录、聊天、Agent、上传下载、历史、刷新和管理；Desktop 覆盖本地与远程。
同服务器、同负载做一次回放对比，分别记录冷启动资源与登录后稳态开销，不据单轮作统计结论。
多轮性能与 Firefox/WebKit 矩阵后续补充。发布检查包括安装包、可信证书、全新目录、旧部署
保留、无系统凭据库调用和所有相关 CI。
